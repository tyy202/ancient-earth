# 非鸟类恐龙分布示意实施计划

用户已确认：仅做科普级大致分布，先做恐龙，继续支持离线和手机。

1. 从 PBDB 获取 Dinosauria^Aves，按现代大陆筛选，保存查询、日期、摘要和可追溯的化石编号。拒绝接口报错或截断结果，不把下载失败当作无记录。
2. 对现有恐龙时代帧采用前后 5 Ma 的范围；过滤年龄区间过宽的记录。各现代大陆的化石仅支持“其对应陆块存在发现记录”，不推断整个大陆遍布恐龙。锚点复用现有 PALEOMAP 年代参考点，明确不是化石原址。
3. 生物下拉菜单默认关闭，可选择非鸟类恐龙。地名和生物开关独立，复用投影、背面隐藏和文字避让。显示年代范围、无标记状态、简短来源说明。
4. 先增加失败测试，再实现数据整理和 UI。验证 65 Ma／现代不显示非鸟类恐龙，220—90 Ma 切换生物数据，关闭地名仍显示生物，离线请求及桌面／手机布局与手势。
5. README 和数据说明记录来源、许可、抽样规则和局限；运行数据进入 js 目录，沿用现有 Docker COPY，无需新增服务或构建依赖。
